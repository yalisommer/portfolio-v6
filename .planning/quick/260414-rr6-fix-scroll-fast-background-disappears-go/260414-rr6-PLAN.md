<objective>
Fix fast-scroll transparency bug: section backgrounds disappear on fast scroll, revealing the aquarium video through them.

Purpose: The Section component currently applies `opacity: 0` via `revealStyle` to the entire `<section>` element, including its `background: var(--ds-bg)`. When scrolling fast, the IntersectionObserver fires too late (or not at all for a fast-passing section), leaving the section transparent. Moving the reveal animation to the inner content `<div>` keeps the section background always opaque while preserving the content fade-in effect.

Output: Updated `src/components/Section.tsx` where the `<section>` element always has a solid background and only the inner content div animates.
</objective>

    The bug: `revealStyle` (opacity + translateY) is spread onto the `<section>` element, making the entire section — including its background — transparent before IntersectionObserver fires.

    Fix: Remove `revealStyle` from the `<section>` element's style prop and apply it to the inner `<div style={innerStyle}>` instead.

    Resulting structure:

    ```tsx
    return (
      <section
        id={id}
        ref={ref as React.RefObject<HTMLElement>}
        style={sectionStyle}          // always opaque background — NO revealStyle here
      >
        <div style={{ ...innerStyle, ...revealStyle }}>  // reveal animates content only
          {children}
        </div>
      </section>
    )
    ```

    `sectionStyle` already has `background: 'var(--ds-bg)'` and `minHeight: '100vh'` — the section is always visible and blocks the aquarium. Only the text/content inside fades + translates on scroll-reveal.
