  <action>
    **Create `src/components/Nav.tsx`**

    Props interface: `{ heroVisible: boolean }`

    **Section IDs and labels** (per D-03):
    Define a constant array of section config objects:
    ```typescript
    const SECTIONS = [
      { id: 'about', label: 'ABOUT' },
      { id: 'experience', label: 'EXPERIENCE' },
      { id: 'education', label: 'EDUCATION' },
      { id: 'skills', label: 'SKILLS' },
      { id: 'projects', label: 'PROJECTS' },
      { id: 'research', label: 'RESEARCH' },
      { id: 'contact', label: 'CONTACT' },
    ] as const
    ```

    **Active section tracking** (per D-07, using research Pattern 4):
    - Use `useState<string>('')` for `activeSection`
    - In a `useEffect`, query all 7 section elements by ID (`document.getElementById`)
    - Create a single IntersectionObserver with `rootMargin: '-40% 0px -55% 0px'` (the research-recommended midpoint trick -- creates a 5% trigger zone at the top third of the viewport)
    - In the observer callback, iterate entries: if `entry.isIntersecting`, set `activeSection` to `entry.target.id`
    - Observe all 7 section elements. Clean up with `observer.disconnect()` in the effect cleanup.

    **Nav bar styling** (per D-01, D-02):
    - `position: 'fixed'`, `top: 0`, `left: 0`, `right: 0`, `zIndex: 100`
    - Height: `52px` (Claude's discretion, within 48-56px range)
    - `display: 'flex'`, `alignItems: 'center'`, `justifyContent: 'center'`, `gap: '0.25rem'`
    - `background: 'rgba(0, 0, 0, 0.75)'` (per D-02)
    - `backdropFilter: 'blur(12px)'` AND `WebkitBackdropFilter: 'blur(12px)'` (Safari prefix, per research Pitfall 1)
    - `borderBottom: '1px solid rgba(255, 255, 255, 0.12)'` (per D-02)
    - `padding: '0 2rem'`

    **Nav visibility transition** (per D-04):
    - `opacity: heroVisible ? 0 : 1`
    - `transform: heroVisible ? 'translateY(-100%)' : 'translateY(0)'`
    - `pointerEvents: heroVisible ? 'none' as const : 'auto' as const`
    - `transition: 'opacity 0.2s ease-out, transform 0.2s ease-out'`

    **Nav links** (per D-03, D-05, D-06):
    - Render as `<a>` elements with `href={`#${section.id}`}` (relies on `scroll-behavior: smooth` in App.css for smooth scrolling, per NAV-02)
    - Link text styling: `fontFamily: "'JetBrains Mono', monospace"`, `fontSize: '0.7rem'`, `textTransform: 'uppercase'`, `letterSpacing: '0.15em'`, `textDecoration: 'none'`
    - Inactive color: `'rgba(255, 255, 255, 0.45)'` (per D-06)
    - Active color: `'#e0e0e0'` (per D-06), with `transition: 'color 0.2s ease'`
    - Active link wrapped in a `<span className="motif-corners">` with `padding: '4px 6px'`, `display: 'inline-block'` (per D-05 -- detection-box bracket motif from motifs.css)
    - Inactive links do NOT get the motif-corners class

    **Important implementation details:**
    - Nav always renders in the DOM (never conditionally unmounted) -- visibility is CSS-only (per research anti-pattern guidance)
    - Do NOT add `onClick` handlers for scroll -- `<a href="#id">` with `scroll-behavior: smooth` handles it natively (per research "Don't Hand-Roll" section)
    - The `position: relative` on `.motif-corners` is already set in motifs.css -- do not duplicate it inline

    **Update `src/App.tsx`**

    - Import `Nav` from `'./components/Nav'`
    - Render `<Nav heroVisible={heroVisible} />` as the first child inside the fragment (`<>`), before `<AquariumLanding>`
    - No other changes to App.tsx
