    **Step 1: Create `src/hooks/useScrollReveal.ts`** (per D-11, D-12, D-13, D-14)

    Export a `useScrollReveal` function that:
    - Takes an optional `threshold` parameter (default `0.1`)
    - Returns `{ ref: RefObject<HTMLElement | null>, revealed: boolean }`
    - Creates an IntersectionObserver that watches the ref element
    - On first `isIntersecting === true`, sets `revealed = true` and calls `observer.disconnect()` (one-shot, per D-12)
    - Cleans up the observer in the effect cleanup function
    - Follows established patterns: `useRef`, `useState`, `useEffect` with cleanup

    Exact implementation from research Pattern 3.

    **Step 2: Create `src/components/Section.tsx`** (per D-21, D-22)

    Props interface: `{ id: string; children: React.ReactNode }`

    The component:
    - Calls `useScrollReveal(0.1)` to get `{ ref, revealed }`
    - Renders a `<section>` element with the `id` and `ref` attached
    - Inline styles (per project convention):
      - `minHeight: '100vh'`
      - `background: 'var(--ds-bg)'` (uses token, per DS-05)
      - `padding: '6rem 2rem'` (per D-21)
      - `display: 'flex'`, `flexDirection: 'column'`, `alignItems: 'center'`
      - Scroll-reveal transition: `opacity` 0/1, `transform` translateY(30px)/0, `transition: 'opacity 0.6s ease-out, transform 0.6s ease-out'` (per D-11)
    - Inner div: `maxWidth: '1200px'`, `width: '100%'`, `margin: '0 auto'` (per D-21)
    - Respect `prefers-reduced-motion`: check `window.matchMedia('(prefers-reduced-motion: reduce)')` and if matched, set transition duration to near-zero or skip translateY. Simplest approach: add a `@media (prefers-reduced-motion: reduce)` consideration — since we use inline styles, check via a `useEffect` or just set `transition: 'none'` when reduced motion is preferred. Alternatively, initialize `revealed = true` when reduced motion is preferred so no animation occurs. Choose the simplest approach.
    - Uses `export default function Section` pattern (per project convention)
