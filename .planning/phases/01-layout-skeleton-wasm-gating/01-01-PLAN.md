4. **Add heroRef** inside the component body (before the existing hooks):
   ```typescript
   const heroRef = useRef<HTMLDivElement>(null)
   ```

5. **Add IntersectionObserver useEffect** (per D-04, D-05 -- after the existing hooks, before the return):
   ```typescript
   useEffect(() => {
     const el = heroRef.current
     if (!el) return

     const observer = new IntersectionObserver(
       ([entry]) => {
         onHeroVisibility(entry.isIntersecting)
       },
       { threshold: 0.1 }
     )

     observer.observe(el)
     return () => observer.disconnect()
   }, [onHeroVisibility])
   ```

6. **Update the `isActive` computation** (per D-06) from:
   ```typescript
   const isActive = canDetect && detectionOn
   ```
   to:
   ```typescript
   const isActive = canDetect && detectionOn && heroVisible
   ```
   This gates inference on hero visibility. When `heroVisible` is false, `isActive` becomes false, which sets `active={false}` on `DetectionCanvas`, stopping the RAF loop.

7. **Update the outer div** (per D-02):
   - Add `ref={heroRef}` to the root `<div>`
   - Remove `overflow: 'hidden'` from the style object (it currently has `overflow: 'hidden'`)
   - Keep `position: 'relative'`, `width: '100vw'`, `height: '100vh'`
   - Result: `<div ref={heroRef} style={{ position: 'relative', width: '100vw', height: '100vh' }}>`

8. **Add fade styling to the detection toggle button** (per D-07):
   Add these three CSS properties to the button's existing inline style object:
   ```typescript
   opacity: heroVisible ? 1 : 0,
   pointerEvents: heroVisible ? 'auto' as const : 'none' as const,
   transition: 'opacity 0.25s ease',
   ```
